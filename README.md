# 提交规则

## 1.版本+代码号+优先级作为标题

{

版本：每一开发周期有一个固定的版本号

代码号：定义提交的类型，是新增，错误，修改

优先级：作为下一日首选的开发目标

}

## 2.提交应在各个分支中进行新增，修改，测试通过后，并入主分支并关闭此分支，开发进行模块化处理，所以关闭后的分支为弱分支，不在活跃，而新功能从新分支开启，开发周期结束后删除所有弱分支
